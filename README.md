# Ultimate Editor

PKHeX 26.10.18 / .NET 10용 읽기 전용 입수 후보 목록 플러그인입니다.
개체 생성·PokeFinder 계산·세이브 주입은 아직 없습니다.

## 지원 게임과 기준

PKHeX 26.10.18에 실제 출현 조회기가 있는 본가 39개 버전의 후보 목록을 지원합니다.

- 레드·그린/해외 블루·일본 블루·피카츄 / 골드·실버·크리스탈
- 루비·사파이어·에메랄드 / 파이어레드·리프그린
- 디아루가·펄기아·기라티나 / 하트골드·소울실버
- 블랙·화이트 / 블랙2·화이트2
- X·Y / 오메가루비·알파사파이어
- 썬·문 / 울트라썬·울트라문 / 레츠고 피카츄·이브이
- 소드·실드 / 브릴리언트 다이아몬드·샤이닝 펄 / 레전드 아르세우스
- 스칼렛·바이올렛 / 레전드 Z-A

현재 PKHeX가 연 세이브의 정확한 버전으로 적용합니다. 지방 도감 제한 없이 게임 전체 후보를 조회합니다.
구작처럼 정확한 버전을 구분할 수 없는 세이브는 기본 게임 선택 창을 표시하고 세이브 자체는 변경하지 않습니다.
GO·콜로세움·XD·포켓몬 목장·포켓워커·드림레이더는 본가 직접 입수 목록에 포함하지 않습니다.
출현 조회기가 없는 버전이나 향후 작품은 지원한다고 표시하지 않습니다.

## 설치

PKHeX 종료 후 dist/UltimateEditor.dll 하나를 PKHeX 옆 plugins 폴더에 복사하고 다시 실행합니다.
세이브를 연 뒤 도구 메뉴의 'Ultimate Editor — 입수 후보 목록'을 선택합니다.
PKHeX 버전 변경 시 API 호환성을 다시 확인해야 합니다.

## 선정 규칙

- 직접 포획·선물·NPC 교환 후보. 교배 제외, 게임 내 선물 알 포함.
- 동일 종/폼의 야생 출현은 최저 레벨 기록 하나. 동률은 장소 ID → 방법 → 기록 ID 순.
- 같은 버전에서 야생 미진화체가 있으면 야생 진화형 제외.
- 고정 심볼도 야생 포획으로 처리. 선물·NPC 교환에는 야생 진화형 제외를 적용하지 않음.
- 선택형 스타팅·선물·배회 전설은 현재 모든 후보를 표시. 세이브 선택 기록과 연결은 미구현.
- 행은 종이 아니라 입수 경로. 같은 종의 선물·교환 경로는 따로 표시될 수 있음.

## 거울 버전

기본값 꺼짐. 켜면 기본 게임과 같은 그룹의 나머지 버전을 모두 포함합니다.
R/S/E, D/P/Pt, G/S/C는 다른 두 버전, 1세대는 나머지 세 버전, 나머지 쌍 버전은 다른 한 버전입니다.
BW와 B2W2, SM과 USUM, 원작과 리메이크는 별개 그룹입니다.
레전드 아르세우스·Z-A는 단일 작품으로 거울 옵션을 비활성화합니다.
기본 버전에서 입수 가능한 종은 기본 버전만 남기며, 상대 버전 전용 종만 파란색으로 추가합니다.
여러 상대 버전에 같은 종이 있으면 GameProfile.Groups의 그룹 순서에서 먼저 해당되는 버전을 씁니다.
거울 중복 제거 단위는 사용자 정책에 따른 종 번호입니다. 폼별 소유 여부를 고려한 거울 병합은 아직 아닙니다.

상대 버전별 OT/TID/SID/성별/언어 입력란과 '상대 세이브에서 가져오기'를 제공합니다.
가져오기는 세이브를 읽기만 하며 버전 및 언어가 맞는지 검사합니다.
TID/SID는 PKHeX에 표시된 형식으로 입력합니다. 7세대 이후 TID는 6자리이며 표시 SID도 필요합니다.
내부적으로 ID32 = 표시SID × 1,000,000 + 표시TID로 복원한 뒤 원본 16비트 TID/SID로 나눕니다.
오버플로 조합은 거부합니다. TID만으로 SID를 추정하거나 임의 생성하지 않습니다.
1·2세대 SID는 미사용(0). 이후 세대의 최대 이름 길이와 지원 언어도 구분합니다.
목록은 미입력 상태로 볼 수 있으며 JSON 저장 시 필수값을 검사합니다.
JSON MirrorTrainers의 TID/SID는 내부 원본 값입니다. NPC 교환·배포의 고정 OT/ID에는 일반 입력값을 덮어쓰면 안 됩니다.

## 검증 범위와 한계

PKHeX 템플릿은 가능한 개체 출신을 설명하며 외부 자원 없이 입수 경로를 수행할 수 있다는 증명은 아닙니다.
현재 목록은 검토용 후보이며 다음 보완이 남아 있습니다.

- 직접 배포는 수령 대상 검증 전까지 후보 조회에서 제외.
- 이벤트 포획 후보는 포함될 수 있음. RequiresEvent는 FatefulEncounter 표식이며 모든 선행 조건을 표현하지 않음.
- NPC 교환 요구 종, 교배 제외 정책에 맞는 최소 레벨 보정.
- 버전별 화석 아이템 확보, GBA 더블슬롯, 통신/선행 포켓몬/배포 개체 의존 조건.
- 4세대 먹고자 꿀나무처럼 트레이너 ID별로 달라지는 장소는 생성 전 추가 검증 필요.
- D/P/Pt 포켓몬 목장 선물은 외부 게임 출처라 자동 선정에서 제외.
- 장소는 PKHeX 표시 언어의 게임별 지역 이름으로 표시하고 내부 ID도 함께 유지합니다. 번역이 없으면 영어, 그마저 없으면 장소 정보 없음으로 표시합니다. 선물 알은 별도 수령 장소가 있으면 이를 표시합니다. JSON에도 LocationName과 EggLocation을 포함합니다.
- 지역폼/분기 진화의 야생 미진화체 판정은 현재 종 번호 중심이며 폼별 선행 조건 정교화가 남아 있습니다.
- 1·2세대 템플릿은 원본 세이브에 남지 않는 장소/버전별 세부 조건이 생략될 수 있어 완전한 입수 경로 증명으로 쓰지 않습니다.
- GUI는 사용자 실행 확인 필요. 빌드·선정 로직·실제 테이블·세이브 읽기는 자동 검사.

SV와 Z-A 조회는 26.10.18 공개 iterator의 상태 전이 반복 문제를 피하기 위해 동일 내장 테이블을 읽는 호환 어댑터를 사용합니다.
호스트 PKHeX나 vendor 원본은 수정하지 않습니다. 내부 필드가 바뀐 버전은 명시적인 호환 오류를 냅니다.
일반 SV 레이드는 해당 버전에서 호스팅 가능한 기록만 포함하고 배포 레이드는 미검증 이벤트로 제외합니다.

## 빌드

ultimate_editor에서 ./build-plugin.ps1 실행.
프로젝트 내부 SDK(tools/dotnet)와 PKHeX 공식 26.10.18 소스(vendor/pkhex/kwsch-PKHeX-bfe89c7)를 사용합니다.
39개 버전 테이블과 선정/통합 규칙 및 표시 ID 변환을 검사합니다. 지원별 요약은 output/support-summary.json에 기록합니다.
상위 폴더의 .sav는 읽어서 버전 연동 및 원본 해시 보존만 검사하며 저장하지 않습니다.
보고서는 output/catalog-{버전}-Game.json 및 output/catalog-{버전}-mirrors.json에 기록합니다.
예전 도감 스냅샷은 data/reference에 참고용으로 남아 있으며 실행 시 사용하지 않습니다.
플러그인 소스는 GPL-3.0-or-later, PKHeX 소스/라이선스는 vendor에 보존합니다.

## Python 보조 도구

Python 3.11 이상, 외부 패키지 없음. 플러그인 실행에는 Python이 필요하지 않습니다.

```powershell
python poke_prepare.py inventory
python poke_prepare.py encounters --versions firered leafgreen --start 1 --end 151
python poke_prepare.py encounters --versions firered --offline
python -m unittest discover -s tests -v
```

PokéAPI 응답을 data/cache에 캐시하고 CSV/JSON으로 출력합니다.
출현 기록 없음은 입수 불가 판정이 아닙니다. 같은 출력 폴더의 보고서는 재실행 시 교체됩니다.
