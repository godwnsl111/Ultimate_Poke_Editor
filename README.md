# Ultimate Editor

PKHeX 26.10.18 / .NET 10용 입수 후보 조회 및 빈 박스 주입 플러그인입니다.
일반 입수 템플릿으로 개체 생성·검사·복제본 검증 후 열린 세이브에 반영합니다. PokeFinder와 사용자 지정 이로치/IV 조건은 아직 연결하지 않았습니다.

## 지원 게임과 기준

PKHeX 26.10.18에 실제 출현 조회기가 있는 본가 39개 버전의 후보 목록을 지원합니다.

- 레드·그린/해외 블루·일본 블루·피카츄 / 골드·실버·크리스탈
- 루비·사파이어·에메랄드 / 파이어레드·리프그린
- 디아루가·펄기아·기라티나 / 하트골드·소울실버
- 블랙·화이트 / 블랙2·화이트2
- X·Y / 오메가루비·알파사파이어
- 썬·문 / 울트라썬·울트라문 / 레츠고 피카츄·이브이
- 소드·실드 / 브릴리언트 다이아몬드·샤이닝 펄 / 레전드 아르세우스
- 스칼렛·바이올렛 / 레전드 Z-A

현재 PKHeX가 연 세이브의 정확한 버전으로 적용합니다. 지방 도감 제한 없이 게임 전체 후보를 조회합니다.
구작처럼 정확한 버전을 구분할 수 없는 세이브는 기본 게임 선택 창을 표시하고 세이브 자체는 변경하지 않습니다.
GO·포켓몬 목장·포켓워커는 포함하지 않습니다. 콜로세움·XD 및 드림 AR 서처는 아래 연동 옵션으로 별도 표시합니다.
출현 조회기가 없는 버전이나 향후 작품은 지원한다고 표시하지 않습니다.

## 설치

PKHeX 종료 후 dist/UltimateEditor.dll 하나를 PKHeX 옆 plugins 폴더에 복사하고 다시 실행합니다.
세이브를 연 뒤 도구 메뉴의 'Ultimate Editor — 입수 후보 목록'을 선택합니다.
PKHeX 버전 변경 시 API 호환성을 다시 확인해야 합니다.

## 선택 개체 생성·박스 반영

1. 목록의 '추가' 체크박스로 원하는 경로를 선택합니다. 일반 입수는 같은 종/폼당 경로 하나만 선택합니다. 직접 배포는 카드별로 중복 선택 가능합니다.
2. '가능 항목 선택'은 선행 확인이 필요 없는 일반 입수만 종/폼당 하나씩 선택합니다. 직접 배포·교환·이벤트는 원하는 행을 개별 선택합니다.
3. 거울 출신은 해당 버전 트레이너 정보가 필요합니다. 6·7세대 거울 출신은 국가/지역까지 보존하기 위해 상대 세이브에서 가져오기를 사용하세요.
4. '선택 개체 생성·주입 미리보기'에서 템플릿 기본 입수값으로 생성하고 개체 적법성을 검사합니다.
5. 현재 박스→뒤쪽 박스→앞쪽 박스 순으로 빈 슬롯만 배정합니다. 기존 개체·알·보호/잠금 슬롯·의심되는 데이터는 덮어쓰지 않습니다.
6. 세이브 복제본에 추가해 저장 데이터 재판독·체크섬·개체 적법성·기존 슬롯 보존을 확인합니다.
7. 박스/슬롯과 실제 생성 결과를 미리 본 뒤 '열린 세이브에 반영'을 누릅니다.
8. 최종 파일 저장은 PKHeX의 저장 기능으로 수행합니다. 플러그인은 원본 파일을 직접 저장하지 않습니다.

공간 부족 또는 선택 개체 하나라도 생성/검사에 실패하면 전체 배치를 반영하지 않습니다.
미리보기 후 세이브가 변경되거나 다른 세이브가 열리면 반영을 거부합니다.
'이번 주입 취소'는 현재 플러그인 창에서 마지막 주입 한 번을 취소합니다. 그 이후 다른 편집이 있으면 자동 취소를 거부합니다.
PKHeX 기본 Undo 기록과 자동 연결되지는 않습니다. 플러그인 창을 닫으면 이 취소 기록은 사라집니다.
취소는 디스크에 이미 저장한 파일을 다시 쓰지 않으므로, 저장 후 취소했다면 PKHeX에서 다시 저장해야 합니다.

### 이번 주입 범위

- 일반 야생/고정 포획, 선물, 선물 알 템플릿의 기본 생성값. 닉네임/IV/성격/기술을 임의로 재작성하지 않습니다.
- 알 상태/부화 여부는 템플릿의 실제 생성 결과를 미리보기에 표시합니다.
- NPC 교환·이벤트 포획도 생성 가능합니다. 이벤트 포획의 선행조건 설명은 참고용이며 확인 체크 없이 생성합니다. NPC 교환·외부 연동은 '교환·연동 선행 조건 확인'을 사용합니다.
- NPC 교환은 교환 레벨 열을 제공합니다. 알려진 3·4세대 요구 종은 교배 없이 직접 출현/일반 레벨업으로 얻는 최소 레벨로 보정합니다. 미판정 경로는 사용자가 교환 레벨을 입력해야 합니다.
- 이 확인은 자동 검증 완료를 뜻하지 않습니다. NPC 요구 종/아이템/대화/외부 의존 조건은 세이브만으로 모두 증명할 수 없으며 미확인 부분을 사용자에게 표시합니다.
- 동적 폼은 여전히 주입에서 제외합니다.
- 적법성 통과가 현재 스토리 진행, 선택형 선물, 외부 자원 없이 모든 선행 조건을 충족했다는 보장은 아닙니다.
- 입수 조건 상세 검증과 폼별 의존 조건의 한계는 아래 항목을 확인하세요.
- 기본/거울 버전 및 명시적으로 지원하는 GC·AR 연동만 다룹니다. 세대 전송/HOME 변환은 수행하지 않습니다.
- 생성 계산 중 취소는 현재 개체의 기본 생성 호출이 끝난 후 적용됩니다.

## 선정 규칙

- 직접 포획·선물·NPC 교환 후보. 교배 제외, 게임 내 선물 알 포함.
- 동일 종/폼의 야생 출현은 최저 레벨 기록 하나. 동률은 장소 ID → 방법 → 기록 ID 순.
- 같은 버전에서 야생 미진화체가 있으면 야생 진화형 제외.
- 고정 심볼도 야생 포획으로 처리. 선물·NPC 교환에는 야생 진화형 제외를 적용하지 않음.
- 선택형 스타팅·선물·배회 전설은 현재 모든 후보를 표시. 세이브 선택 기록과 연결은 미구현.
- 행은 종이 아니라 입수 경로. 같은 종의 선물·교환 경로는 따로 표시될 수 있음.

## 거울 버전

기본값 꺼짐. 켜면 기본 게임과 같은 그룹의 나머지 버전을 모두 포함합니다.
R/S/E, D/P/Pt, G/S/C는 다른 두 버전, 1세대는 나머지 세 버전, 나머지 쌍 버전은 다른 한 버전입니다.
BW와 B2W2, SM과 USUM, 원작과 리메이크는 별개 그룹입니다.
레전드 아르세우스·Z-A는 단일 작품으로 거울 옵션을 비활성화합니다.
기본 버전에서 입수 가능한 종은 기본 버전만 남기며, 상대 버전 전용 종만 파란색으로 추가합니다.
여러 상대 버전에 같은 종이 있으면 GameProfile.Groups의 그룹 순서에서 먼저 해당되는 버전을 씁니다.
거울 중복 제거 단위는 사용자 정책에 따른 종 번호입니다. 폼별 소유 여부를 고려한 거울 병합은 아직 아닙니다.

상대 버전별 OT/TID/SID/성별/언어 입력란과 '상대 세이브에서 가져오기'를 제공합니다.
가져오기는 세이브를 읽기만 하며 버전 및 언어가 맞는지 검사합니다.
TID/SID는 PKHeX에 표시된 형식으로 입력합니다. 7세대 이후 TID는 6자리이며 표시 SID도 필요합니다.
내부적으로 ID32 = 표시SID × 1,000,000 + 표시TID로 복원한 뒤 원본 16비트 TID/SID로 나눕니다.
오버플로 조합은 거부합니다. TID만으로 SID를 추정하거나 임의 생성하지 않습니다.
1·2세대 SID는 미사용(0). 이후 세대의 최대 이름 길이와 지원 언어도 구분합니다.
목록은 미입력 상태로 볼 수 있으며 JSON 저장 시 필수값을 검사합니다.
JSON MirrorTrainers의 TID/SID는 내부 원본 값입니다. NPC 교환·배포의 고정 OT/ID에는 일반 입력값을 덮어쓰면 안 됩니다.

## 직접 배포 (이상한 카드 데이터베이스)

'직접 배포 표시'를 켜면 금색 행으로 카드별 개체를 표시합니다. 기본 필터는 `현재 수령 언어 (공통 포함)`이며, 특정 언어 또는 `모든 언어 (검토용)`도 선택할 수 있습니다. 기본 게임은 열린 세이브의 언어, 거울 게임은 상대 트레이너 입력란의 언어로 필터링합니다. 상대 언어를 바꾸거나 가져오면 목록도 갱신됩니다. `배포수령언어` 열은 카드 DB의 수령 제한을 표시합니다.
일반 입수 목록에 같은 종이 있어도 유지하며 서로 다른 배포 카드도 각각 선택할 수 있습니다.
동일 카드/수령 버전의 파일 중복만 제거합니다. 수령 언어가 다른 거울 게임을 선택할 수 있도록 카드의 수령 버전별 행은 유지합니다.
같은 카드/수령 버전의 동일 행을 배치 안에서 여러 번 선택하지는 않으며 기존 박스 보유 개체와의 종 중복은 제한하지 않습니다.

- PKHeX의 EncounterEvent.GetAllEvents가 제공하는 내장/이미 로드된 로컬 카드 사용.
- 포켓몬/배포 알만 사용. 배포 아이템 카드는 개체로 변환하지 않음.
- 수령 게임의 세대/형식/버전과 카드 제한을 확인. 고정 출신 게임은 수령 게임으로 바꾸지 않음.
- 고정 OT/ID/기술/볼/색이 다른 조건은 카드 생성기가 적용. 결과는 개체 적법성/박스 재판독 검사.
- 표의 배포명·수령 언어 조건을 확인. 전체 언어를 표시해도 호환되지 않는 언어는 생성 전에 거부합니다. 수령 언어 제한과 개체의 고정 언어는 구분합니다. 공통 배포는 한국어 세이브에도 표시하며, 배포 국가와 수령 언어가 항상 같다고 가정하지 않습니다. DB에 없는 국가 제한을 언어만으로 복원하지 않습니다.
- HOME 전용 선물과 레인저 마나피 알 등 외부 서비스/게임 출처는 이 직접 배포 목록에서 제외.
- 배포 기간이 끝난 과거 카드도 대상. 실제 카드 수령 기록이나 스토리/티켓 플래그를 세이브에 등록하는 기능은 아님.
- 이 PKHeX 카드 DB는 4세대 이후 데이터입니다. 1~3세대 직접 배포는 다른 형태의 템플릿/수령 대상 조사 없이는 지원하지 않습니다. 일반 이벤트 포획과 구분하세요.

4세대 PCD의 고정 Version은 개체 출신이며 수령 대상은 CardCompatibility를 확인합니다.
PCD를 ReadUInt16LittleEndian으로 읽을 때 D=0x0400, P=0x0800, Pt=0x1000, HG=0x0080, SS=0x0100을 사용합니다.
원 연구의 표기는 바이트 순서가 다릅니다: [Mystery Gift Editor 제작자의 하드웨어 검증 설명](https://projectpokemon.org/home/forums/topic/5870-pok%C3%A9mon-mystery-gift-editor-v143-now-with-bw-support/page/3/).
호환 비트가 없는 불명확한 카드는 추정해 포함하지 않습니다.
5~9세대는 PKHeX의 카드별 수령 제한 API를 사용하며 외부 메타데이터(RestrictVersion/RestrictLanguage)를 복제 시 보존합니다.

## 검증 범위와 한계

PKHeX 템플릿은 가능한 개체 출신을 설명하며 외부 자원 없이 입수 경로를 수행할 수 있다는 증명은 아닙니다.
현재 목록은 검토용 후보이며 다음 보완이 남아 있습니다.

- 직접 배포는 위 카드 DB 경로로 포함합니다. 데이터에 없는 실제 배포 대상·지역 제한까지 새로 복원하는 기능은 아닙니다.
- 이벤트 포획 후보는 포함될 수 있음. RequiresEvent는 FatefulEncounter 표식이며 모든 선행 조건을 표현하지 않음.
- NPC 최소 레벨 자동 보정은 현재 알려진 FR/LG/R/S/E/D/P/Pt 요구 종과 직접 출현·일반 레벨업 경로에 한정합니다. 나머지 교환은 수동 레벨/조건 확인이 필요합니다.
- 버전별 화석 아이템 확보, GBA 더블슬롯, 통신/선행 포켓몬/배포 개체 의존 조건.
- 4세대 먹고자 꿀나무처럼 트레이너 ID별로 달라지는 장소는 생성 전 추가 검증 필요.
- D/P/Pt 포켓몬 목장 선물은 외부 게임 출처라 자동 선정에서 제외.
- 장소는 PKHeX 표시 언어의 게임별 지역 이름으로 표시하고 내부 ID도 함께 유지합니다. 번역이 없으면 영어, 그마저 없으면 장소 정보 없음으로 표시합니다. 선물 알은 별도 수령 장소가 있으면 이를 표시합니다. JSON에도 LocationName과 EggLocation을 포함합니다.
- 지역폼/분기 진화의 야생 미진화체 판정은 현재 종 번호 중심이며 폼별 선행 조건 정교화가 남아 있습니다.
- 1·2세대 템플릿은 원본 세이브에 남지 않는 장소/버전별 세부 조건이 생략될 수 있어 완전한 입수 경로 증명으로 쓰지 않습니다.
- GUI는 사용자 실행 확인 필요. 빌드·선정 로직·실제 테이블·메모리 복제본 주입/재판독/취소는 자동 검사.

SV와 Z-A 조회는 26.10.18 공개 iterator의 상태 전이 반복 문제를 피하기 위해 동일 내장 테이블을 읽는 호환 어댑터를 사용합니다.
호스트 PKHeX나 vendor 원본은 수정하지 않습니다. 내부 필드가 바뀐 버전은 명시적인 호환 오류를 냅니다.
일반 SV 레이드는 해당 버전에서 호스팅 가능한 기록만 포함하고 배포 레이드는 미검증 이벤트로 제외합니다.

## 빌드

ultimate_editor에서 ./build-plugin.ps1 실행.
프로젝트 내부 SDK(tools/dotnet)와 PKHeX 공식 26.10.18 소스(vendor/pkhex/kwsch-PKHeX-bfe89c7)를 사용합니다.
39개 버전 테이블과 선정/통합 규칙 및 표시 ID 변환을 검사합니다. 지원별 요약은 output/support-summary.json에 기록합니다.
상위 폴더의 .sav는 읽어서 버전 연동 및 원본 해시 보존만 검사하며 저장하지 않습니다.
보고서는 output/catalog-{버전}-Game.json 및 output/catalog-{버전}-mirrors.json에 기록합니다.
예전 도감 스냅샷은 data/reference에 참고용으로 남아 있으며 실행 시 사용하지 않습니다.
플러그인 소스는 GPL-3.0-or-later, PKHeX 소스/라이선스는 vendor에 보존합니다.

## Python 보조 도구

Python 3.11 이상, 외부 패키지 없음. 플러그인 실행에는 Python이 필요하지 않습니다.

```powershell
python poke_prepare.py inventory
python poke_prepare.py encounters --versions firered leafgreen --start 1 --end 151
python poke_prepare.py encounters --versions firered --offline
python -m unittest discover -s tests -v
```

PokéAPI 응답을 data/cache에 캐시하고 CSV/JSON으로 출력합니다.
출현 기록 없음은 입수 불가 판정이 아닙니다. 같은 출력 폴더의 보고서는 재실행 시 교체됩니다.


### 콜로세움·XD / 드림 AR 서처 연동

- R/S/E/FR/LG: `콜로세움 / XD 포함` 옵션. 원본별 OT/TID/SID/언어 입력 또는 해당 GC 세이브 가져오기. 보라색 행과 연동출처 열로 구분합니다. 기본/거울 목록과 별도로 유지하여 같은 종의 다른 출처를 선택할 수 있습니다.
- GC 다크 포켓몬은 PKHeX의 출처별 PID/IV 생성기로 리라이브 완료 개체를 생성하고 CK3/XK3→PK3 전용 변환을 적용합니다. 출신, 고정 트레이너, 리본, 기술은 네이티브 템플릿과 변환 규칙을 유지합니다. XD 다크 포켓몬의 이로치 금지도 유지합니다. 배틀산 칠색조를 포함하며 보너스 디스크 배포는 제외합니다. 카드 e 룸은 일본어 원본만 지원합니다.
- B2/W2: `드림 AR 서처 포함` 옵션. 26종·폼, 수령 세이브의 트레이너, 드림볼, 특성, 비이로치 조건을 사용합니다. 배지 0개=5, 1~2개=10, 3~4개=20, 5~6개=30, 7~8개=40레벨로 생성합니다. BW 및 다른 세대에서는 이 옵션을 사용할 수 없습니다.
- 해금·리라이브·교환 진행 조건 및 전설의 세이브당 수령 제한은 목록의 선행조건을 읽고 확인해야 합니다. 외부 원본의 실제 진행도나 과거 수령 이력을 자동 증명하거나 변경하지 않습니다. 카드 삽입 전설 조건은 [AR 서처 공식 안내](https://www.pokemon.co.jp/ex/ar_searcher/characters/rekidai.html)와 pinned PKHeX 데이터의 출처 주석을 따릅니다.
- 연동도 빈 슬롯 보존, 미리보기, 적법성 검사, 직전 주입 취소를 거칩니다. 원본 세이브 파일에는 자동 저장하지 않습니다.


### 이벤트 포획 확인 단계

쉐이미·다크라이 및 기타 이벤트 포획은 `선행 조건 확인` 체크 없이 바로 선택·생성할 수 있습니다. 조건 설명은 참고 정보로 남기고, NPC 교환·GC/AR 연동의 확인 단계는 유지합니다. 입수 경로·출신 언어 제한 및 생성 개체의 PKHeX 적법성 검사는 계속 적용합니다. 티켓·스토리 플래그를 변경하는 기능은 아닙니다.

한국어 기라티나의 꽃의낙원 쉐이미는 pinned PKHeX EncounterVerifier에서 미배포로 판정하므로 직접 배포 카드로 선택해야 합니다. 이 언어 제한은 이벤트 선행조건 확인과 별도로 유지하며 목록의 입수언어안내에 표시합니다.
